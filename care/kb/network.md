# Network and service issues

## Outages
If a customer reports no signal across a whole area, check for an outage and create a network ticket with the ZIP code and the time the issue started. Network engineering reviews network tickets within 4 hours.

## Device troubleshooting
For dropped calls on one device only, restart the device, toggle airplane mode, and confirm Wi-Fi Calling is on. If the issue continues, create a device ticket.

## 5G coverage
5G coverage depends on the device and the location. Customers can check coverage by ZIP code on the coverage map.
